FULL-STACK · WORKFLOW

Job Tracker

An inbox is a terrible database, so I turned mine into one. Sign in with Google, then sync two ways: label a thread yourself, or let it scan the inbox and infer which stage each application reached. Stage changes ping me on Feishu. The interesting part was never the interface — it was building a reliable state machine out of messy human email.

  • 2sync modes
  • Autostage detection

DATA → DECISION

What Makes a Price Feel Unfair?

Surge pricing is an optimisation problem that keeps producing angry customers. Using 107,752 NYC taxi-commission trip records merged with weather and zone data, we modelled how fares are actually built — then optimised for passenger utility loss instead of platform revenue, under real constraints like New York’s minimum wage. It ends in a usable pricing formula, not a chart.

  • 107,752trips analysed
  • R² .754fare model fit
  • $2.23+ $2.68/mile

Regression · Nonlinear programming · NYC TLC open data

Team of 6 — my part: data pipeline and the prescriptive model.
